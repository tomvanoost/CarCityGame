# Roadmap

Where the game is going, and the next steps in order. Each scheduled run does **the first unchecked
step** only (see "Each run" in `CLAUDE.md`), then moves it to `docs/PROGRESS.md`.
Every step must respect the requirements in `CLAUDE.md` (no violence, simple UI, fast on tablets, NL/EN).

## Goal
A friendly, non-violent open-world city for kids aged ~6–12: drive and walk around a small, lively city,
earn money with simple jobs, buy cars and clothes, collect stickers. Looks good, runs smoothly on
tablets, Dutch first with English. Overview and history: `docs/PLAN.md`.

## Next steps

New gameplay features, one per run (the user's request: no more "more realistic" graphics steps —
the realistic trees glitched and were reverted). Each one small, kid-friendly, simple big-button UI,
NL + EN, works with keyboard, tablet controls and controllers. Everything costs in-game money only
(the game stays free: no real money, no ads).

- [ ] **Sledge hill in the desert dunes**: a sandboard rental (€10) to slide down the biggest dune,
  with a lift (a rope tow) back up.
- [ ] **Library / quiz corner**: a little library in the lake town with picture quizzes about the game
  world (NL + EN), €10 per right answer and a "clever" sticker.
